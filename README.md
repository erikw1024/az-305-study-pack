# AZ-305 Study Workspace

A source-linked study pack for an AZ-104-qualified learner preparing for AZ-305, written in Australian English.

## Open the site

https://erikw1024.github.io/az-305-study-pack/

## Included

- Four-domain syllabus and architecture decision frameworks
- 28 correction notes and review status for all 28 supplied walkthroughs
- Six-week study schedule and eight design exercises
- 32 original multiple-choice scenarios with explanations and browser-local progress
- 83 reference links, with source credibility and access limitations
- Editable Markdown download and print-friendly reading

The official signed-in practice assessment was not reproduced. ExamTopics is a third-party discussion reference; its page returned HTTP 403 during preparation. The original uploaded guides are not redistributed here.

## Editing

`study-content.md` is the editable study manuscript. `index.html`, `styles.css` and `app.js` form a buildless static site. The downloadable manuscript is under `downloads/`. The original local authoring tools are not required to serve the site.

Progress and selected answers are stored only in the current browser's local storage. No analytics, external scripts, accounts or server are used. Clearing site data clears progress. The full manuscript remains available without JavaScript.

## GitHub Pages

Publish `main` from the repository root in **Settings > Pages**. `.nojekyll` keeps the static files unchanged. All assets use relative paths so the site works under the project path.
